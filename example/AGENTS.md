# Expo SDK 57

This example targets Expo SDK 57 (React Native 0.86, New Architecture only).
Read the versioned docs at https://docs.expo.dev/versions/v57.0.0/ before
writing any code.

It renders `expo-thinking-orbs` from the repo root's `src/` via the
`expo-thinking-orbs-source` export condition (see `metro.config.js`).
