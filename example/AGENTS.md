# Expo SDK 56

This example targets Expo SDK 56 (React Native 0.85, New Architecture only).
Read the versioned docs at https://docs.expo.dev/versions/v56.0.0/ before
writing any code.

It renders `expo-thinking-orbs` from the repo root's `src/` via the
`expo-thinking-orbs-source` export condition (see `metro.config.js`).
